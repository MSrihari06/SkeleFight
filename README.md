# 💀 SkeleFight

A 2D/3D action game project built in **Unity** featuring custom player controllers, combat mechanics, and physics simulations.

---

## 🎮 About the Project
**SkeleFight** is a game development project focused on core combat mechanics, smooth player movement, and interactive gameplay loops. Built as an exploration of game physics and script architecture within Unity.

---

## ✨ Key Features
* **Custom Player Controller:** Smooth movement, jumping, and interaction handling via C# scripts.
* **Combat Mechanics:** Hitbox detection, health tracking, and enemy reaction states.
* **Physics Integration:** Rigidbody-based movement and collision handling.
* **Modular Codebase:** Clean C# script organization for easy expansion and debugging.

---

## 🛠️ Built With
* **Engine:** Unity (2D / 3D)
* **Language:** C#
* **Version Control:** Git & GitHub
